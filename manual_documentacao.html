1. Visão Geral do Sistema e Acesso Inicial

O ERP Industrial & MRP I é uma plataforma integrada sob medida desenvolvida para gerenciar de ponta a ponta as operações de uma manufatura. O sistema resolve o desafio de conectar a área comercial, a engenharia de produtos, o planejamento da produção (PCP), a execução no chão de fábrica e a apuração contábil/financeira (DRE).

Endereços de Acesso Local aos Serviços

• Interface Web do Usuário (Frontend): http://localhost:3000
• Servidor de APIs e Regras de Negócio (Backend): http://localhost:3001/api

1.1. Como Fazer o Primeiro Acesso (Login)

Para garantir a segurança das informações operacionais e financeiras, o sistema opera com autenticação via tokens criptografados (JWT) e níveis de acesso (RBAC).

  1. Abra o navegador de sua preferência (Edge, Chrome, Firefox) e acesse http://localhost:3000/login.
  2. Informe as credenciais corporativas do administrador configuradas na instalação:
    • E-mail: admin@erp.local
    • Senha: admin123
  3. Clique no botão "Entrar no Sistema". O sistema autenticará as credenciais no backend e redirecionará automaticamente para o Painel Geral.
Nota de Segurança

O token de sessão permanece salvo de forma segura no navegador. Cada requisição ao backend é validada contra o perfil do operador (ex: Operador não tem permissão para alterar o DRE financeiro).

1.2. O Fluxo Operacional Integrado do ERP

O ERP funciona através de gatilhos automáticos entre os módulos. Quando uma ação ocorre em um departamento, o sistema alimenta os departamentos subsequentes sem retrabalho manual:

1
Pedido Venda
Comercial lança venda aprovada do cliente
2
Cálculo MRP
Explosão da BOM e verificação de saldo
3
Ordem de Produção
Reserva de matéria-prima e liberação
4
Chão de Fábrica
Apontamento de operador e baixa de estoque
5
DRE & Caixa
Atualização instantânea do lucro e custos

2. Manual do Usuário: Telas e Operações

2.1. Painel Geral de Operações (Dashboard)

Acesso: Menu lateral → Painel Geral (ou rota raiz /).

Esta tela reúne os principais Indicadores-Chave de Desempenho (KPIs) da indústria para tomada de decisão rápida pela gerência:

  • OEE da Planta (Overall Equipment Effectiveness): Mostra o percentual de eficiência real das máquinas considerando disponibilidade, desempenho e qualidade. O sistema compara com a meta operacional (ex: 80%).
  • Ordens de Produção (OP) Ativas: Quantidade de lotes em andamento no chão de fábrica e lotes já liberados pelo PCP aguardando máquina.
  • Gatilho de Estoque Mínimo: Alerta em tempo real sobre matérias-primas que atingiram o limite crítico de segurança e precisam de compra urgente.
  • Resultado Operacional (DRE Sintético): Lucro acumulado no período e margem líquida gerencial.

2.2. Cadastros Base: Itens e Parceiros Comerciais

Acesso: Menu lateral → Cadastros Base (rota /cadastros).

É a espinha dorsal de dados do sistema, dividida em duas abas funcionais:

Aba 1: Cadastro de Itens e Insumos

Permite registrar e consultar qualquer item físico que circula pela fábrica:

Campo Tipo Descrição e Importância
Código Texto Identificador único (SKU). Ex: MP-CHAPA-01 ou PA-ARMARIO-01.
Tipo de Item Seleção Matéria-Prima, Produto Acabado, Semiacabado ou Embalagem.
Unidade Seleção KG, UN, Metros (M) ou Litros (L).
Custo Unitário (R$) Valor Valor de compra para alimentar o Custo dos Produtos Vendidos (CPV).
Estoque Mínimo Quantidade Gatilho que avisa o setor de compras antes que a matéria-prima esgote.

Aba 2: Cadastro de Parceiros (Clientes & Fornecedores)

Armazena a carteira comercial de clientes para emissão de pedidos e fornecedores para envio de ordens de cotação e importação de notas fiscais XML.

2.3. Engenharia de Produto & BOM (Bill of Materials)

Acesso: Menu lateral → Engenharia (BOM) (rota /engenharia).

A BOM é a fórmula/receita industrial do produto. Nesta tela, o usuário visualiza:

  • Estrutura em Árvore: Quais matérias-primas e componentes semiacabados compõem 1 unidade do produto acabado.
  • Coeficiente de Consumo: Quantidade exata gasta por unidade fabricada (ex: 18,5 KG de chapa de aço por armário).
  • Perda Técnica Estimada (%): Margem de refugo natural no processo (ex: 3% de sobra de corte), calculada automaticamente pelo MRP.
  • Tempo Padrão de Fabricação: Minutos previstos de máquina e montagem para cálculo de capacidade de fábrica.

3. Manual do Usuário: PCP, Chão de Fábrica e Financeiro

3.1. PCP — Planejamento MRP I & Ordens de Produção

Acesso: Menu lateral → PCP & MRP I (rota /pcp).

O MRP I (Material Requirements Planning) é o cérebro do planejamento industrial. Como utilizá-lo:

  1. Selecione o Produto Acabado que a fábrica deseja produzir.
  2. Digite a Quantidade a Produzir (ex: 50 unidades).
  3. Clique no botão "Executar Explosão MRP".
  4. Interpretação do Resultado:
    • O sistema multiplica a quantidade pelas receitas cadastradas na BOM;
    • Consulta o saldo real do estoque;
    • Se o saldo for insuficiente, gera uma indicação em vermelho: Gerar Ordem de Compra;
    • Se houver saldo suficiente, exibe em verde: Estoque Disponível.
  5. Clique em "Emitir Ordem de Produção (OP)" para autorizar o início da fabricação.

3.2. Chão de Fábrica — Terminal Touch para o Operador

Acesso: Menu lateral → Chão de Fábrica (rota /chao-de-fabrica).

Projetado especificamente para ser usado em tablets industriais ou telas sensíveis ao toque na linha de produção:

  • Identificação do Posto: O operador visualiza sua máquina (ex: CT-CORTE — Máquina Laser CNC) e a OP em produção.
  • Botão Touch "Iniciar Operação": Dispara a contagem do tempo de fabricação real.
  • Contador de Peças Boas (+ / -): Botões grandes para o operador registrar peças inspecionadas e aprovadas.
  • Contador de Peças Refugadas (+ / -): Registro de peças com defeito de corte/solda para cálculo de perdas financeiras.
  • Botão "Concluir Ciclo": Finaliza a produção, registrando o histórico no banco de dados e dando entrada imediata no produto acabado.

3.3. Suprimentos, Estoque & Rastreabilidade FIFO

Acesso: Menu lateral → Estoque & Lotes (rota /estoque).

Gerencia a integridade física dos materiais:

  • Controle de Lotes: Cada recebimento possui número de lote e data de entrada.
  • Regra FIFO (First In, First Out / PEPS): O sistema garante que o lote mais antigo seja consumido primeiro na linha de montagem, evitando deterioração ou vencimento.
  • Importação XML NF-e: Leitura de notas fiscais eletrônicas de fornecedores para entrada em lote sem digitação.

3.4. Financeiro Integrado & DRE Gerencial

Acesso: Menu lateral → Financeiro & DRE (rota /financeiro).

Apresenta a demonstração contábil do resultado do exercício baseada em eventos reais da fábrica:

  • Receita Bruta: Somatório de todos os pedidos de venda faturados.
  • Custo dos Produtos Vendidos (CPV): Soma dos insumos consumidos nas OPs somado ao custo/hora dos centros de trabalho.
  • Lucro Bruto Industrial: Margem de contribuição direta da manufatura.
  • Resultado Líquido e Margens (%): Indicador de rentabilidade líquida da indústria.

4.2. O Algoritmo Matemático do MRP I (Implementação Técnica)

O serviço MrpService (localizado em apps/api/src/modules/mrp/mrp.service.ts) processa as necessidades de materiais aplicando a fórmula de explosão com perdas técnicas:

Equações do Motor de MRP

1. Necessidade Bruta ($NB$):
NB = Quantidade_Solicitada × Coeficiente_BOM × (1 + Taxa_Perda / 100)

2. Saldo Real em Estoque ($SE$):
SE = ∑ (Entradas_Compra + Entradas_Producao) - ∑ (Saidas_Producao + Saidas_Venda)

3. Necessidade Líquida ($NL$):
NL = Math.max(0, NB - SE)

4. Tomada de Decisão do Algoritmo:
Se NL > 0 e item for Matéria-Prima → EMITIR_ORDEM_COMPRA.
Se NL > 0 e item for Semiacabado → EMITIR_ORDEM_PRODUCAO.
Se NL == 0 → ESTOQUE_SUFICIENTE (Gera reserva de saldo).

5. Modelagem do Banco de Dados & Guia de Comandos

5.1. Entidades Principais (Prisma Schema)

A modelagem de dados foi estruturada com integridade referencial estrita e transações ACID:

Tabela (Model) Função no Sistema Relacionamentos Principais
users Usuários e operadores autenticados Possui histórico em production_logs
partners Clientes e Fornecedores Vinculado a sale_orders e purchase_orders
items Catálogo de materiais e produtos Pai em boms, filho em bom_items, estoque em stock_lots
boms Cabeçalho da estrutura de produto 1 Item Produto Acabado → N bom_items
production_orders Ordens de Produção (OP) Vinculada ao Produto, Pedido e Apontamentos
production_logs Apontamentos de horas/peças do operador Registra operador, centro de trabalho e refugos
stock_movements Kardex contábil de movimentações Alimenta saldos e rastreia NF-e / OP de origem
financial_transactions Contas a pagar, receber e DRE Categorizado por DRECategory

5.2. Guia de Comandos Rápidos para Manutenção

Para desenvolvedores e administradores que precisem gerenciar o sistema via linha de comando:

Comando O que executa
npm run dev:web Inicia o frontend Next.js na porta 3000 em modo desenvolvimento com Hot-Reload.
npm run dev:api Inicia a API NestJS na porta 3001 com monitoramento de alterações de código.
npm run build Compila ambos os módulos (API e Web) para produção gerando os pacotes finais.
npm run db:seed Executa o script de carga inicial recriando os dados de teste e o usuário Admin.
npx prisma studio Abre uma interface visual no navegador para inspecionar e editar qualquer tabela do banco.
docker compose up -d Sobe o container do banco PostgreSQL corporativo e pgAdmin (porta 5050).

O sistema encontra-se estruturado, funcional e pronto para uso operacional da Fase 1 (Fundação e Autenticação) e Fase 2 (Cadastros Base, Terminal de Fábrica e DRE). As etapas futuras (Semana 3 a 8) poderão ser ativadas conforme a demanda da indústria.
